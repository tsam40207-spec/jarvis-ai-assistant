# Contributing to JARVIS AI Assistant

Thank you for your interest in contributing! Here's how you can help.

## How to Contribute

### Reporting Bugs
- Use GitHub Issues
- Include: OS, Python version, error message, steps to reproduce

### Suggesting Features
- Open an Issue with tag `[Feature Request]`
- Describe the feature and why it would be useful

### Code Contributions
1. Fork the repository
2. Create a branch: `git checkout -b feature/your-feature`
3. Make your changes
4. Test thoroughly
5. Commit: `git commit -m 'Add your feature'`
6. Push: `git push origin feature/your-feature`
7. Open a Pull Request

## Code Style
- Python: Follow PEP 8
- JavaScript: Use modern ES6+
- Comments: Write clear, helpful comments
- Naming: Use descriptive variable names

## Priority Areas
- New voice commands
- Additional AI engine integrations
- Mobile responsive dashboard
- Memory/context persistence
- Browser automation
- Multi-language support

## Code of Conduct
Be respectful, inclusive, and constructive. We're all here to build something amazing.
